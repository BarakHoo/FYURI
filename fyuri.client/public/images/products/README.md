## Image Specifications

### Thumbnails (main product images)
- Size: 400x400px square
- Format: JPG
- File size: Under 200 KB
- Background: Clean white or transparent
- Centered product shot

### Detail Images
- Size: 800x800px or larger
- Format: JPG
- File size: Under 500 KB
- Additional angles, close-ups, or in-use shots

## Tips for Product Photography

1. **Clean background**: Use white or light gray background
2. **Good lighting**: Bright, even lighting without harsh shadows
3. **Multiple angles**: Front, side, top, mounted views
4. **Details**: Show important features like tubes, controls, mounts
5. **In-use shots**: Show the device being worn or used (if possible)
6. **Consistent style**: All products should have similar lighting and framing

## Placeholder Images

If you don't have actual product images yet, you can:
1. Use stock photos of similar night vision devices
2. Create simple placeholder graphics with the product name
3. Leave empty - the app will show a broken image icon until images are added

## Adding New Products

When adding new products through the admin panel:
1. Take/prepare product images following the specs above
2. Name files consistently: `product-sku.jpg`, `product-sku-1.jpg`, etc.
3. Upload or place files in this directory
4. Reference the image paths in the admin panel when creating the product
